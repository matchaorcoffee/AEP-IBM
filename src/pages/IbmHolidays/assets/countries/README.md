# Country Images

Place one image per country here. Suggested filenames:

- `Brazil.jpg`
- `CostaRica.jpg`
- `India.jpg`
- `Mexico.jpg`
- `Philippines.jpg`
- `USA.jpg`
- `Canada.jpg`

Once added, import each file in `IbmHolidaysPage.tsx` and set the `src` field
on the matching entry in the `countries` array.
